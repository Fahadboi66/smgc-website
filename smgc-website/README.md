# SMGC Website

A modern, responsive company website built with React, Vite, and Tailwind CSS.

## Tech Stack

- React 18
- Vite 5
- Tailwind CSS 3
- Framer Motion (animations)
- Lucide React (icons)
- Vitest + Testing Library (tests)

## Getting Started

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Testing

Run all tests once:

```bash
npm test
```

Run tests in watch mode:

```bash
npm run test:watch
```

## Project Structure

```
src/
├── components/    # UI components (Hero, Navbar, Services, etc.)
├── constants/     # Shared constants (contact info, etc.)
├── data/          # Static data (services, timeline)
├── hooks/         # Custom React hooks
├── styles/        # Global CSS
└── tests/         # Test files
```
